HEAD IN THE CLOUDS — OPTIONAL CINEMATIC ASSET SLOTS / v29

The site is designed to remain beautiful with these empty.
When a professionally authored WebM/MP4 exists, put it here and set the matching
path in assets.config.js.

Core slots:
- aoko-atmosphere.webm       -> Aoko profile atmosphere (currently intentionally empty)
- hero-clouds.webm           -> hero/title atmosphere
- character-atmosphere.webm  -> shared Characters layer
- hisano-sea.webm            -> Hisano map/coast
- history-era.webm           -> legacy History layer
- gallery-atmosphere.webm    -> Gallery atmosphere
- chapter-portal.webm        -> chapter opening
- closing-coast.webm         -> final coastline
- night-sky.webm             -> final sky
- then-map-overlay.webm      -> Then / Now

v29 precision slots:
- story-atmosphere.webm      -> Story
- characters-nature.webm     -> Characters
- history-sky.webm           -> History
- read-atmosphere.webm       -> Read
- scenes-atmosphere.webm     -> Scenes from Hisano

Recommended: muted, looping WebM; transparent WebM when the export supports it.
The website must never require these files to lay out correctly.
